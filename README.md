# Crystal Loom

> **免責聲明**：本站為測試版，巨集由 Raphael 求解器計算，僅供參考。實際結果以遊戲內為準。

FF14 生產職 A 方案（5734／5517／649）100 級配方巨集查詢。

- 輸入製作畫面的「難度」和品質上限，或打中文品名，找出對應巨集。
- 需要墊 HQ 的配方，會列出實際級距與最少要墊的 HQ（半成品名稱只是舉例，可自行挑選）。
- 巨集由 [Raphael](https://github.com/KonaeAkira/raphael-rs) 求解器算出；配方資料取自 [xivapi/ffxiv-datamining](https://github.com/xivapi/ffxiv-datamining)；繁中技能名取自 [Teamcraft](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft)。
